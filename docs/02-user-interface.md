# 두 번째 작업 기록: 입력 폼과 결과 시각화

## 작업 개요

- 작업일: 2026년 9월 23일
- 단계: 3일 MVP 중 2일 차 핵심 작업
- 목표: 첫 번째 작업에서 만든 계산 코어를 실제 한 페이지 사용자 흐름에 연결
- 결과: 입력, 계산, 경고, 결과 카드, 차트, 출처를 포함한 반응형 UI 완성

두 번째 작업에서는 `src/domain`의 계산 함수를 다시 작성하지 않고 React 화면에서 그대로 호출했습니다. 사용자는 페이지를 연 뒤 예시 결과를 바로 확인하거나 자신의 값을 입력해 새 결과를 계산할 수 있습니다.

## 구현한 사용자 흐름

```text
서비스 목적 확인
  → 월 실수령액·필수지출·현재 비상금 입력
  → 투자 성향·ISA 유형 선택
  → 계산하기
  → CMA·ISA 배분안 확인
  → 비상금 상태 확인
  → 36개월 예상 결과 확인
  → 일반계좌·ISA 세금 차이 확인
  → 계산 기준과 출처 확인
```

## 화면 구성

### 1. 서비스 소개

첫 화면에서 서비스의 목적과 범위를 짧게 설명합니다.

- 사회초년생을 위한 3분 월급 가이드
- 실수령액 기준 계산
- 비상금 상태 반영
- 3년 세금 비교
- 실제 상품 추천이 아닌 교육용 시뮬레이션임을 사전 안내

### 2. 입력 폼

다음 다섯 가지 값을 받습니다.

| 입력 | 처리 방식 |
| --- | --- |
| 월 실수령액 | 0원보다 큰 원 단위 정수 |
| 월 필수지출 | 0원 이상의 원 단위 정수 |
| 현재 비상금 | 0원 이상의 원 단위 정수 |
| 투자 성향 | 안정형·중립형·적극형 |
| ISA 유형 | 일반형·서민형·잘 모르겠어요 |

금액 필드는 모바일 숫자 키패드를 사용할 수 있도록 `inputMode="numeric"`을 지정했습니다. 입력 오류는 해당 필드 바로 아래에 표시하고 `aria-invalid`, `aria-describedby`로 연결했습니다.

투자 성향과 ISA 유형은 키보드로도 선택 가능한 기본 라디오 버튼을 사용하되 카드 형태로 표현했습니다.

### 3. 입력 변경 상태

입력값이나 선택 항목이 바뀌면 기존 결과를 즉시 덮어쓰지 않고 다음 안내를 표시합니다.

```text
입력이 변경됐어요. 다시 계산하면 결과에 반영됩니다.
```

사용자는 어떤 입력으로 결과가 만들어졌는지 구분할 수 있고, 계산 버튼을 눌렀을 때만 결과가 갱신됩니다.

### 4. 배분 결과 카드

필수지출, CMA, ISA를 서로 다른 색의 카드로 보여줍니다.

- 필수지출: 중립 회색
- CMA: 비상금 성격의 민트
- ISA: 장기 투자 성격의 파랑

실수령액 전체에서 각 금액이 차지하는 비율도 하나의 누적 막대로 표시합니다. 금액과 비율을 함께 제공해 색만으로 정보를 구분하지 않도록 했습니다.

### 5. 비상금 진행률

현재 비상금과 목표 금액을 비교해 진행률을 표시합니다.

- 비상금 목표 금액
- 현재 비상금
- 목표 달성률
- 목표까지 남은 금액
- 목표 달성 시 CMA 추가 배정이 0원인 이유

진행률 막대에는 `role="progressbar"`와 현재 값을 제공했습니다.

### 6. 계산 경고

도메인 함수가 반환하는 경고 코드를 사용자 문구로 변환했습니다.

| 경고 코드 | 화면 문구의 목적 |
| --- | --- |
| `EXPENSE_EXCEEDS_INCOME` | 필수지출이 실수령액보다 큰 상태 설명 |
| `NO_DISPOSABLE_INCOME` | CMA·ISA 배정액이 0원인 이유 설명 |
| `ISA_ANNUAL_LIMIT_EXCEEDED` | 기본 연간 납입한도와 실제 잔여 한도 확인 안내 |
| `ISA_TYPE_DEFAULTED` | 일반형으로 임시 계산한 사실 안내 |

경고 영역은 `aria-live="polite"`로 선언해 재계산 후 보조기술에서도 변화를 알 수 있게 했습니다.

### 7. 36개월 시뮬레이션 차트

외부 차트 라이브러리를 추가하지 않고 반응형 SVG로 구현했습니다.

- 납입 원금: 회색 점선
- 예상 평가액: 파란 실선과 면적 강조
- 1·12·24·36개월 축 표시
- 금액 축 표시
- 차트 외부에 납입 원금과 예상 평가액 숫자 제공
- SVG에 제목과 접근 가능한 설명 제공

모바일에서는 차트 자체의 가독성을 유지하기 위해 내부 최소 폭을 보존하고 차트 영역만 가로 스크롤할 수 있게 했습니다.

### 8. 세금 비교

일반계좌와 ISA의 예상 세금을 막대와 금액으로 함께 표시합니다.

- 과세 대상 예상 수익
- 일반계좌 예상 세금
- ISA 예상 세금
- 예상 절세액
- 적용 ISA 비과세 한도
- 수수료, 해외 원천징수, 상품별 과세 차이 미반영 안내

### 9. 계산 기준과 출처

페이지 하단에 비상금 정책, ISA 비과세 한도, 기본 연간 납입한도와 확인 기준일을 표시했습니다. 외부 출처는 새 탭에서 열리며 `rel="noreferrer"`를 적용했습니다.

## 반응형 디자인

### 데스크톱

- 입력 폼과 결과를 좌우 2열로 배치
- 입력 폼을 화면 상단에 고정해 긴 결과를 확인하는 동안에도 입력 영역 유지
- 결과 카드 3열 배치

### 태블릿

- 입력 폼과 결과를 위아래로 전환
- 금액 필드를 2열로 배치
- 입력 폼의 고정 위치 해제

### 모바일 360px

- 페이지 여백과 카드 패딩 축소
- 결과 카드 세로 배치
- 투자 성향과 ISA 유형 선택지를 세로 배치
- 세금 비교와 출처 카드를 한 열로 전환
- 차트 영역의 가로 스크롤 허용
- 상단 보조 메뉴 숨김

## 접근성 및 사용성

- 모든 입력 필드에 명시적 `label` 연결
- 투자 성향과 ISA 유형에 `fieldset`, `legend` 사용
- 키보드 포커스 스타일 제공
- 결과 영역 갱신 후 결과 제목으로 포커스 이동
- 결과 영역으로 부드러운 스크롤
