# 사용자 화면 보완 작업 기록: CMA·ISA 이해 가이드

## 작업 개요

- 작업일: 2026년 9월 23일
- 단계: 두 번째 사용자 화면 작업의 후속 보완
- 목표: 계산 결과에 등장하는 CMA와 ISA의 역할을 금융 초보자가 이해할 수 있도록 설명

기존 `docs/02-user-interface.md`에는 입력 폼과 결과 시각화를 구현한 두 번째 작업이 이미 기록되어 있습니다. 이 문서는 그 화면을 보완한 별도 작업을 중복 없이 기록하기 위해 세 번째 문서로 추가했습니다.

## 문제 정의

기존 화면은 CMA와 ISA의 월 배정액을 보여주지만 다음 질문에 직접 답하지 못했습니다.

- CMA와 ISA는 각각 무엇인가?
- 두 계좌는 어떤 목적으로 사용하는가?
- 둘 다 반드시 가입해야 하는가?
- RP형, MMF형, MMW형 CMA는 무엇이 다른가?
- 원금 손실과 예금자보호는 어떻게 다른가?

단순히 상품 설명을 늘어놓으면 계산 흐름이 무거워지고 특정 금융상품을 추천하는 것처럼 보일 수 있습니다. 따라서 계산 입력은 그대로 유지하면서 결과를 확인한 사용자가 필요할 때 추가 설명을 읽는 구조로 설계했습니다.

## 확정한 UI 구조

### 1. 결과 화면의 표현 보완

- 결과 카드의 `CMA` 표기를 `비상금 · CMA 등`으로 변경했습니다.
- 월급 배분 범례에서는 같은 금액을 `비상금`으로 표시했습니다.
- CMA가 비상금을 보관할 수 있는 유일한 방법이라는 인상을 줄이지 않도록 문구를 조정했습니다.
- 결과 마지막에 `CMA와 ISA가 낯설다면 차이부터 확인해 보세요` 링크를 추가했습니다.

### 2. CMA·ISA 비교 섹션

계산 영역과 `계산 기준과 출처` 영역 사이에 `CMA와 ISA, 목적이 달라요` 섹션을 추가했습니다.

각 계좌는 다음 세 가지 정보로 설명합니다.

- 한 문장 정의
- 적합한 자금의 성격
- 원금 손실, 상품 차이 등 가입 전 확인할 점

두 설명 카드는 데스크톱에서 나란히 비교할 수 있고, 모바일에서는 CMA와 ISA 순서로 세로 배치됩니다.

### 3. “둘 다 해야 하나요?” 안내

사용자가 두 상품을 모두 가입해야 한다고 오해하지 않도록 별도 안내문을 추가했습니다.

핵심 원칙은 다음과 같습니다.

1. CMA와 ISA는 모두 필수가 아닙니다.
2. 비상금이 부족하면 CMA를 포함한 현금성 자산을 먼저 확보합니다.
3. 생활비와 비상금을 제외한 여유자금이 생겼을 때 ISA를 검토합니다.

### 4. CMA 유형 펼침 영역

계산 화면의 복잡도를 높이지 않도록 CMA 유형은 기본적으로 접힌 `<details>` 요소 안에 배치했습니다. JavaScript 없이도 키보드와 보조기술로 열고 닫을 수 있습니다.

설명한 유형은 다음과 같습니다.

| 유형 | 운용 방식 | 핵심 주의사항 |
| --- | --- | --- |
| RP형 | 환매조건부채권 | 예금자보호 대상이 아니며 증권사 신용위험 확인 |
| MMF형 | 국공채 등 단기금융상품에 투자하는 펀드 | 실적배당, 원금 손실 가능, 예금자보호 대상 아님 |
| MMW형 | 랩계약을 통해 증권금융 예수금 등 단기자산 운용 | 실적과 보수 확인, 예금자보호 대상 아님 |
| 종금형 | 종합금융회사에서 취급하는 예외 유형 | 상품별 보호 여부와 취급 금융회사 확인 |

특정 유형을 추천하지 않고 금융회사마다 수익률, 자동투자 시간, 출금 조건이 다르다는 안내도 함께 표시했습니다.

## 사실관계 교정

초기 조사 문서의 `RP형 CMA는 예금자보호 예외`라는 표현을 화면에 사용하지 않았습니다.

- RP형과 MMF형 CMA는 예금자보호 대상이 아닙니다.
- MMW형도 일반적으로 예금자보호 대상이 아닙니다.
- 종금형처럼 보호 대상에 해당하는 상품은 별도 확인이 필요합니다.
- 2025년 9월 1일부터 보호 대상 예금의 한도는 한 금융회사에서 1인당 원금과 소정의 이자를 합해 1억원입니다.

또한 CMA 전체를 `매일 이자가 붙는 통장`으로 단정하지 않고, 유형별 단기 금융상품에 자동으로 운용되어 수익 계산 방식과 위험이 달라진다고 설명했습니다.

## 출처 관리

`src/domain/assumptions.ts`에 `PRODUCT_GUIDE_SOURCES`를 추가해 확인일과 출처 URL을 중앙 관리합니다.

- 금융투자협회 CMA 업무관련 모범규준
- 금융위원회 예금보호한도 안내
- 국가법령정보센터 ISA 세제 기준

화면 하단에서도 확인일과 각 출처 링크를 직접 열 수 있습니다.

## 접근성 및 반응형 처리

- 상단 메뉴에 `CMA·ISA 알아보기` 앵커 링크를 추가했습니다.
- CMA 유형은 네이티브 `<details>`와 `<summary>`로 구현했습니다.
- 요약 요소와 출처 링크에 키보드 포커스 표시를 적용했습니다.
- 720px 이하에서는 비교 카드와 CMA 유형 카드를 한 열로 배치합니다.
- 390px 모바일 화면에서 문장 잘림, 가로 넘침, 카드 겹침이 없는지 확인했습니다.
